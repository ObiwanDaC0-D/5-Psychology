01 · CLASSICAL TEST THEORY

True score and measurement error

Classical test theory represents an observed score as true score plus error: X = T + E. Adjust the modeled reliability and observe repeated scores for the same hypothetical person.

02 · ITEM RESPONSE THEORY

Item difficulty and discrimination

Explore a two-parameter logistic (2PL) model. The curve describes the probability of a correct response as a function of latent ability, assuming the model fits.

03 · STANDARD SCORES

z scores, T scores, and percentiles

Percentiles assume a normal reference distribution and should not be treated as universal population norms.

02 · SOCIAL IDENTITY
